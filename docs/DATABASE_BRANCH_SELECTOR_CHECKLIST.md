# Database Branch Selector Manual Check

1. Login as a user with the `pusat` role.
2. Open the Database module.
3. Select Magelang from `Pilih Cabang`.
4. Confirm the URL contains `?branch_id=<Magelang ID>`.
5. Confirm the branch heading, Google Sheet link, presence scope, table data, and sync scope all show Magelang.
6. Select another accessible branch and repeat the URL and page-scope checks.
7. Run `Sync Sekarang` and confirm the selected branch is synced instead of Kantor Pusat.
